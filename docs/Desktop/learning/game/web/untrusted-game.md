# Untrusted

### What is it?

Untrusted is a meta-JavaScript adventure game where players modify the game's source code to progress through levels. It combines coding with puzzle-solving in a unique and engaging way.

### Why Play Untrusted?

- **Learn JavaScript**: Improve your coding skills by directly modifying game logic.
- **Creative Problem-Solving**: Think outside the box to solve puzzles.
- **Fun and Interactive**: Experience a game that blurs the line between player and developer.

### Getting Started

1. Visit the [Untrusted website](https://alexnisnevich.github.io/untrusted/).
2. Start the game and read the instructions.
3. Modify the JavaScript code to progress through levels.

### Tools and Resources

- **JavaScript Documentation**: Refer to [MDN Web Docs](https://developer.mozilla.org/en-US/docs/Web/JavaScript) for help.
- **Code Editor**: Use the in-game editor to modify code.
- **Community**: Join forums to share solutions and strategies.
